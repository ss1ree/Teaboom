# Карточка товара «Ананасовый улун» — Teaboom.ru

Тестовое задание на позицию **HTML-верстальщик / Frontend-разработчик**.  
Верстка верхней части карточки товара для интернет-магазина чая [Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

🔗 **Live Demo (GitHub Pages):** https://ss1ree.github.io/Teaboom/

---

## 🛠 Стек технологий

- **HTML5:** семантическая разметка (`<nav>`, `<section>`, `<h1>`, `<ins>`, `<del>`, `<button>`), использование стандартов доступности (`ARIA`, `role="radiogroup"`).
- **CSS3 / SCSS:** препроцессор SCSS, методология **БЭМ (BEM)**, нативные CSS-переменные (`Custom Properties`), CSS Grid и Flexbox.
- **JavaScript (Vanilla JS):** нативный JS без сторонних библиотек и фреймворков.
- **Responsive Web Design:** адаптивная верстка под экраны от 320px до 1440px+.

---

## ✨ Реализованная функциональность

1. **Выбор фасовки товара:**
   - Реализован через доступную радиогруппу (`<input type="radio">` + `<label>`).
   - Переключение фасовки (100 г, 500 г, 1000 г, 5000 г) подсвечивает активное состояние выбранной строки (`:checked`).
   - При переключении в консоль/состояние передаются актуальные `data-*` атрибуты (артикул, цена, скидка).
2. **Кнопка «В корзину»:**
   - Имеет стилизованные базовое и hover-состояния.
   - Предотвращает нежелательное всплытие событий (`stopPropagation`).
3. **Адаптивность:**
   - Корректное отображение на Desktop (1440px), Tablet (768px) и Mobile (375px и меньше).
   - Оптимизированные отступы и размеры шрифтов.
